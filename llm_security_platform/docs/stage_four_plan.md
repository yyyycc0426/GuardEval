# 阶段四计划：防御策略体系与消融实验

## 目标

阶段四在阶段三分层检测基础上，将平台从“发现攻击”升级为“降低攻击风险”。防御效果必须同时满足安全性和正常业务可用性，不能通过阻断全部请求获得低 ASR。

## 范围

- 输入防御：规范化、编码载荷检测、指令覆盖检测、阻断或系统加固。
- RAG 防御：数据/指令边界、恶意文档隔离、权限过滤、敏感字段过滤和来源保留。
- 输出防御：系统提示、密钥、PII 和攻击成功证据检测，脱敏、改写和复核。
- 九组消融：none、baseline、三个单策略、三个双策略、完整三策略。
- 指标：ASR、误杀率、正常任务成功率、Precision/Recall/F1、FPR/FNR、P50/P95、Token、成本、失败数、复核率。

## 非目标

- 不训练基础安全模型。
- 不把输出脱敏等同于攻击从未发生。
- 不在本阶段引入 Celery、Redis 或前端管理页面。
